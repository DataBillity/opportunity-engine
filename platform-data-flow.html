5. Opportunity Alignment Scoring (40/35/25)

Pure deterministic scoring function used across all workflows. Three weighted dimensions: Capability Alignment (40 pts) measures coverage ratio and maturity. Intent & Timing (35 pts) decays signal confidence by recency. Account Value Fit (25 pts) considers sector, prior relationship, multi-year potential, and reference-account potential. Inbound leads get an additional uplift.

6. Entity Resolution (Account Deduplication)

Four-stage entity resolution ensures every organization resolves to a single account record. Stage 1: Blocking (cheap candidate generation by domain/name). Cross-Cutting Patterns

Classification & Retention

Every row carries a classification (public, internal, confidential, regulated) and retention_class (standard, extended, regulatory, permanent) field, enforcing data governance at the row level.

Append-Only Audit

Cluster G decisions and Cluster J score runs are append-only — UPDATE and DELETE are structurally revoked. The decision table is hash-chained (SHA-256) for tamper detection.

Entity Resolution Anchoring

Cluster A's account table is the single identity anchor (I2). Every lead, opportunity, contact, and solicitation references it. Merges are non-destructive with un-merge support via account_merge.

Operator Auth

Separate from the main schema: operator_credential, operator_profile, and password_reset_token handle session-based JWT authentication with bcrypt password hashing.

AI Gateway Architecture

Judgment Tier (Claude preferred)

Used for outreach generation and high-stakes reasoning. Models: claude-sonnet-5, claude-sonnet-4-6. Falls back to Gemini if Claude API key is missing or fails. Max 1,200 tokens, temperature 0.4.

Extraction Tier (Gemini preferred)

Used for solicitation extraction and partner document parsing. Models: gemini-2.5-flash, gemini-2.0-flash. Falls back to Claude if Gemini is unavailable. JSON mode enabled, temperature 0.1.

Region & Classification Guards

Public/internal data may route to US, EU, or CA. Confidential restricts to US + CA. Regulated data may only be processed in the CA region. Enforced at the gateway level before any API call.

Cost Tracking

Every call logs input/output tokens, cost (USD), latency (ms), model version, and redaction profile to the model_call table in Cluster G for auditability and budget tracking.
